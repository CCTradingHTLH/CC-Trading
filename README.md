# Chu trình suy luận

## Canon Decision Loop

| English | Tiếng Việt |
|----------|------------|
| Observe | Quan sát |
| Auction | Đấu giá |
| Market Context | Bối cảnh thị trường |
| Momentum | Động lượng |
| Structure | Cấu trúc |
| Quality | Chất lượng |
| Decision | Quyết định |
| Signal Weight | Trọng số tín hiệu |
| Scenario Space | Không gian khả năng |
| Execution Planner | Lập kế hoạch thực thi |
| Reality Feedback | Phản hồi từ thực tế |

```text
Observe
      ↓
Auction
      ↓
Market Context
      ↓
Momentum
      ↓
Structure
      ↓
Quality
      ↓
Decision
      ↓
Signal Weight
      ↓
Scenario Space
      ↓
Execution Planner
      ↓
Reality Feedback
      ↓
Observe
```
