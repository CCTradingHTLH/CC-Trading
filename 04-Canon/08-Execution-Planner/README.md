# 08 · Execution Planner

> Biến Decision thành một kế hoạch giao dịch cụ thể.

---

## Vai trò

Execution Planner là tầng nằm giữa Decision và Execution.

Decision trả lời:

> **Làm gì?**

Execution Planner trả lời:

> **Làm như thế nào?**

Execution chỉ trả lời:

> **Thực hiện.**
