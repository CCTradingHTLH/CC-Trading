# Engine 09 · Execution Planner

> Thiết kế kế hoạch thực thi cho từng kịch bản.

---

# Mục đích

Execution Planner chuyển từng Scenario thành một kế hoạch hành động cụ thể.

Mỗi kế hoạch xác định:

- Điều kiện thực thi.
- Điều kiện hủy bỏ.
- Quản trị rủi ro.
- Quản trị vị thế.
