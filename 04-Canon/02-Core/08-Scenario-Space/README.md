# Mục đích

Scenario Space xây dựng toàn bộ các kịch bản có thể xảy ra từ trạng thái hiện tại của thị trường.

Mỗi kịch bản được mô tả bằng:

- Logic
- Điều kiện
- Xác suất
- Trạng thái vô hiệu
