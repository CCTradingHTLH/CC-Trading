# ⚡ Momentum

> **Hiểu sự thay đổi của lực.**

# Mục tiêu

Momentum mô tả cách lực của thị trường thay đổi theo thời gian.

Momentum không trả lời:

> Giá sẽ đi đâu?

Momentum chỉ trả lời:

> Lực đang thay đổi như thế nào?
